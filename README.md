# a-horde-o-bees Claude Code Skills

One Claude Code plugin — `skills` — bundling an authoring kernel for agent-facing artifacts, conduct disciplines for grounded interaction, and operational tooling for the git development cycle, queued fan-outs, PDF export, and transcript analytics.

## Disclaimer

A personal development project: experimental, actively evolving, provided as-is with no stability, support, or backwards-compatibility guarantees. Skills may be added, removed, renamed, or restructured at any time. Use at your own discretion; if something breaks, the LICENSE applies.

## What's inside

- **Authoring kernel** — the disciplines the suite itself is written under: `skill-authoring`, `rule-authoring`, `description-authoring`, `procedure-authoring`, `concise-prose`, `file-decomposition`, `markdown-authoring` (with its own linter), `reauthor`, and `context-mechanics`.
- **Conduct** — `grounded` (verify before acting or asserting), `confirm-shared-intent` (align before acting past ambiguity), `principled-pushback` (surface a conflict before complying with it).
- **Operational** — `git`, one router fronting a Python driver for the development cycle (commit, push, CI, the PR lifecycle, checkpoint, release, repo-health doctor); `apply-over-queue`, a prompt-cached `claude -p` fan-out that pays for a large shared instruction once across many targets; `export-pdf`; and `engaged-time` (below).

Most skills are invoked bare (e.g. `/concise-prose`) and trigger on their own description. The git router dispatches one verb per call (`/git <verb>`, or bare `/git` for the menu).

## Start here

Two artifacts show the method most directly:

- **`context-mechanics`** — how Claude Code assembles an agent's context, every claim source-pinned and graded `[measured]` / `[mechanistic]` / `[behavioral]`, with an explicit epistemic-boundary section and first-party sentinel findings on hook and permission ordering.
- **`procedure-authoring/tests/`** — a cold `claude -p` harness measuring whether a construct's wording evokes the intended behavior, with negative controls that can invalidate a green result table, and a documented A/B whose proposed rename was reverted on the evidence.

## engaged-time, a worked demonstration

`engaged-time` reconstructs engaged time from raw Claude Code transcripts — events → time-blocks → exchanges → topics, rendered as an interactive swimlane timeline, with rollups a consumer may bill on. It is the largest engineering in the suite and the least generalizable, built around the author's own corpus: read it as the architecture applied end-to-end, not as a skill to install as-is.

## How this repo is built

`skills/` is a generated mirror of the live authoring tree, regenerated by `scripts/sync_skills.py` against the allowlist in `.claude/skill-manifest.json`; `scripts/reconcile_manifest.py` diffs the manifest against the live source first, so nothing ships implicitly. `skills/` is never edited directly.

## Installation

```
/plugin marketplace add a-horde-o-bees/claude-plugins
/plugin install skills@a-horde-o-bees
```

Tracks `main` by default. Pin a tagged release with `@vX.Y.Z` on the marketplace add. Restart the session after install so the skills register.

## Updating

```
/plugin marketplace update a-horde-o-bees
/reload-plugins
```

## Removing

```
/plugin uninstall skills
/plugin marketplace remove a-horde-o-bees
```
